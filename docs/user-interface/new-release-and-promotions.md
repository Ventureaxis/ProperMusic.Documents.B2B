Homepage extras

## **New Releases**

The New Release section shows a 4 quadrant square of album covers for the next 4 weeks of upcoming releases.
The album covers are chosen through the admin section of B2B, and can be changed to any product for that release period that is available in B2B.
:::info
![Alt text](img-homepage-new-releases.png)
:::

When clicking on one of these new release sections, you will be navigated to the advanced search page with the release week already set.

:::info
![Alt text](img-new-release-week.png)
:::

## **Promotions**

The Promotions section is a slider that shows current custom promotions set by the sales team.
The promotions are set through the admin section of B2B, and have an image or certain album cover to display on each slide.
These sliders are also connected to set of products that are filtered when any of the slides are clicked on.

:::info
![Alt text](img-homepage-promotions.png)
:::
Similar to the New Releases, clicking on one of these promotions will navigate you to the advanced search page with the promotion filter already set.
